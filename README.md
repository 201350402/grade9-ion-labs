# Grade 9 Ion Labs

Interactive practice for Grade 9 Chemistry: formulas and names of ionic compounds with polyatomic ions and transition metals. Students open them on their own devices.

| Lesson | Lab | File |
|---|---|---|
| 2.8 Formulas and names with polyatomic ions (5E Explore) | Ion Name Lab | `ion-name-lab.html` |
| Practice: polyatomic ions + transition metals (learning menu) | Formula Café | `formula-cafe.html` |

Each page is one self-contained HTML file. The only outside resource is Google Fonts. `index.html` links to both labs. Progress is saved in each student's own browser.
